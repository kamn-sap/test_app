## 🔢 レイヤードアーキテクチャ

Test App は **3 層のレイヤードアーキテクチャ** を採用しています。

### レイヤー構成

```mermaid
graph TB
    subgraph "Presentation Layer"

        Router["🗺️ Vue Router<br/>Route Navigation"]
    end
    
    subgraph "Business Logic Layer"
        Controller["🎮 @RestController<br/>Request Mapping"]
        Service["⚙️ @Service<br/>Business Logic"]
    end
    
    subgraph "Data Access Layer"
        Repository["💾 @Repository<br/>JPA Repository"]
        Entity["📦 @Entity<br/>JPA Entity"]
    end
    
    subgraph "External Resources"
        DB["🗄️ MySQL Database<br/>Primary DB"]

        Cache["📦 Cache<br/>Session/Memory"]
    end
    
    UI -->|Event Handling| Router
    Router -->|API Request| Controller
    Controller -->|Call| Service
    Service -->|Query/Update| Repository
    Repository -->|Map to| Entity
    Entity -->|Persist| DB
    Service -->|Upload/Download| S3
    Controller -->|Session| Cache
    
    style UI fill:#61dafb,stroke:#333,stroke-width:2px,color:#000
```

### 各レイヤーの役割

| レイヤー | コンポーネント | 責務 |
|---------|----------------|------|
| **Presentation Layer** | Vue Components | UI 表示、ユーザーインタクション処理 |
| **Presentation Layer** | Vue Router | ページ遷移、ルート管理 |
| **Controller Layer** | @RestController | HTTP リクエスト受け取り、JSON レスポンス返却 |
| **Service Layer** | @Service | ビジネスロジック実装、トランザクション管理 |
| **Repository Layer** | JPA Repository | データベースアクセス、ORM マッピング |
| **Entity Layer** | @Entity | ドメインオブジェクト定義、テーブル構造定義 |
| **Persistence** | MySQL | データの永続化 |
| **Storage** | Moto S3 | ファイル・オブジェクト管理 |

## 🔄 通信フロー

### ユーザーのログインフロー

```mermaid
sequenceDiagram
    participant Browser as 🌐 Browser
    participant FE as 🖖 Frontend
    participant BE as 🍃 Backend
    participant DB as 🗄️ Database
    
    Browser->>FE: ログイン画面にアクセス
    FE->>FE: ログインフォーム表示
    Browser->>FE: ユーザー名・パスワード入力
    FE->>BE: POST /api/auth/login
    BE->>BE: 入力値検証
    BE->>DB: ユーザー検索
    DB-->>BE: ユーザー情報
    BE->>BE: パスワード検証
    BE->>BE: セッション生成
    BE-->>FE: JWT Token + User Info
    FE->>FE: Token をローカルストレージに保存
    FE->>Browser: Dashboard にリダイレクト
    Browser->>FE: Dashboard 表示
```

### ToDo 作成フロー

```mermaid
sequenceDiagram
    participant FE as 🖖 Frontend
    participant BE as 🍃 Backend
    participant Service as ⚙️ Service
    participant Repo as 💾 Repository
    participant DB as 🗄️ Database
    
    FE->>FE: "新規 ToDo" をクリック
    FE->>FE: ダイアログ表示、フォーム入力
    FE->>BE: POST /api/todos
    BE->>Service: todoService.create(dto)
    Service->>Service: ビジネスロジック検証
    Service->>Repo: save(entity)
    Repo->>DB: INSERT INTO todos
    DB-->>Repo: 成功
    Repo-->>Service: 保存済み Entity
    Service-->>BE: 作成結果
    BE-->>FE: 201 Created + JSON
    FE->>FE: リスト更新
    FE->>Browser: UI 再レンダリング
```
